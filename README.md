# Show Finder

A simple TV guide: search and browse shows, see seasons, episodes and air dates, where each show streams and what it costs, and watch trailers.

Show data comes from [TVmaze](https://www.tvmaze.com). Streaming lists and trailers come from [TMDB](https://www.themoviedb.org), using a key stored as the `TMDB_KEY` repository secret and added to the page when it's deployed.
